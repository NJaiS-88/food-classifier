# Food Classifier Streamlit App

This app classifies uploaded images into three categories:
- 0: Pizza
- 1: Softdrink
- 2: Burger

## Setup

1. Install Python 3.10 or 3.11 (TensorFlow does not support 3.12+ yet).
2. Create a virtual environment:
   ```bash
   python3.10 -m venv venv
   source venv/bin/activate   # On Linux/Mac
   venv\Scripts\activate      # On Windows
